# WindowsVersionsCore

Questo progetto è stato integrato internamente nella soluzione SecureBootWatcher.

## Origine

Originariamente clonato da: https://github.com/robgrame/WindowsVersionsCore

## Integrazione

Il progetto è stato spostato dalla cartella `external/WindowsVersionsCore` alla cartella principale come progetto interno della soluzione il 24 novembre 2025.

## Progetti che lo utilizzano

- `SecureBootDashboard.Api` - Servizi per recuperare informazioni sulle versioni di Windows
- `SecureBootDashboard.WindowsVersionApi` - API autonoma per versioni Windows

## Note di sviluppo

Questo progetto fornisce dati aggiornati sulle versioni di Windows 10 e Windows 11, inclusi:
- Numeri di build
- Date di rilascio
- Supporto e lifecycle
- Informazioni sugli aggiornamenti

Per aggiornamenti futuri, fare riferimento al repository originale se necessario.
