# Readiness Card - Device Details Enhancement

## Overview

La pagina **Device Details** (`/Devices/Details/{id}`) ora include una card dedicata che mostra in dettaglio lo **stato di readiness** per l'aggiornamento Secure Boot UEFI CA 2023.

**Rilascio:** v1.11.1  
**Data:** 2025-01-24

---

## Nuova Card: "Stato di Readiness per Aggiornamento Secure Boot"

### Posizionamento

La card viene visualizzata **dopo la Timeline card** e **prima della Secure Boot Update Progression card** nella pagina dei dettagli del dispositivo.

---

## Componenti della Card

### 1. **Header Dinamico**

```razor
<div class="card-header @(Model.Device.IsReadyToUpdate ? "bg-success text-white" : "bg-warning text-dark")">
```

- **Verde** (`bg-success`): Dispositivo pronto per l'aggiornamento
- **Giallo** (`bg-warning`): Dispositivo non pronto

### 2. **Stato Generale**

Alert box prominente che mostra:

**Dispositivo Pronto:**
```

Tutti i criteri di readiness sono soddisfatti. Il dispositivo può ricevere 
l'aggiornamento del certificato UEFI CA 2023.
```

**Dispositivo Non Pronto:**
```
?? Dispositivo Non Pronto per l'Aggiornamento
Uno o più criteri di readiness non sono soddisfatti. Verifica i dettagli qui sotto.
```

### 3. **Criteri di Readiness** (3 Card)

#### **A. Versione Sistema Operativo**

- **Icona:** `fas fa-windows`
- **Badge:** 
  - ? `OK` (verde) se `IsOSReady = true`
  - ? `Non OK` (rosso) se `IsOSReady = false`
- **Dettaglio:** Mostra `OSEvaluationDetails`

**Esempi di messaggi:**
```
? OS version 10.0.19045 meets requirements (>= 10.0.19045)
? OS version 10.0.18363 does not meet requirements (< 10.0.19045)
? Unknown OS version: 10.0.17763
```

#### **B. Windows UEFI CA 2023**

- **Icona:** `fas fa-certificate`
- **Badge:**
  - ? `Presente` (verde) se `HasWindowsUEFICA2023 = true`
  - ? `Mancante` (rosso) se `HasWindowsUEFICA2023 = false`
- **Dettaglio:** Messaggio esplicativo sulla presenza/assenza del certificato

**Messaggi:**
```

? Il certificato Windows UEFI CA 2023 non è stato trovato nel database delle firme (db).
```

### 4. **Azioni Consigliate**

Sezione alert (`alert-info`) che appare **solo se il dispositivo NON è pronto** (`IsReadyToUpdate = false`).

Suggerisce azioni basate sui criteri non soddisfatti:

```razor
@if (!Model.Device.IsReadyToUpdate)
{
    <div class="alert alert-info mt-3">
        <h6><i class="fas fa-lightbulb"></i> Azioni Consigliate</h6>
        <ul class="mb-0">
            @if (!Model.Device.IsOSReady)
            {
                <li>Aggiorna il sistema operativo alla versione minima richiesta</li>
            }
            @if (!Model.Device.HasWindowsUEFICA2023)
            {
                <li>Esegui il deployment del certificato Windows UEFI CA 2023</li>
            }
            @if (!Model.Device.AreOemCertificatesValid)
            {
                @if (Model.Device.ExpiredOemCertificateCount > 0)
                {
                    <li>Aggiorna i certificati OEM scaduti tramite firmware update</li>
                }
                @if (Model.Device.CriticalOemCertificateCount > 0)
                {
                    <li>Pianifica l'aggiornamento dei certificati OEM in scadenza critica (&lt;90 giorni)</li>
                }
            }
        </ul>
    </div>
}
```

## Modifiche API

### DeviceDetailResponse Enhancement

**File:** `SecureBootDashboard.Api/Controllers/DevicesController.cs`

**Nuove proprietà aggiunte:**

```csharp
public sealed record DeviceDetailResponse(...)
{
    public bool IsReadyToUpdate { get; init; }
    public bool IsOSReady { get; init; }
    public bool AreOemCertificatesValid { get; init; }
    public bool HasWindowsUEFICA2023 { get; init; }
    public int ExpiredOemCertificateCount { get; init; }
    public int CriticalOemCertificateCount { get; init; }
    public int WarningOemCertificateCount { get; init; }
    public int ValidOemCertificateCount { get; init; }
    public string OSEvaluationDetails { get; init; } = string.Empty;
    public string CertificateEvaluationDetails { get; init; } = string.Empty;
}
```

**Logica di valutazione:**

```csharp
// Deserialize certificates for readiness evaluation
SecureBootWatcher.Shared.Models.SecureBootCertificateCollection? certificates = null;
if (latestReport != null && !string.IsNullOrEmpty(latestReport.CertificatesJson))
{
    try
    {
        certificates = System.Text.Json.JsonSerializer.Deserialize<...>(
            latestReport.CertificatesJson);
    }
    catch (Exception ex)
    {
        _logger.LogWarning(ex, "Failed to deserialize certificates for device {DeviceId}", device.Id);
    }
}

// Evaluate readiness using the service
var readinessEvaluation = _readinessService.EvaluateReadiness(
    certificates,
    device.OSVersion,
    device.OSBuildNumber);

return new DeviceDetailResponse(...)
{
    IsReadyToUpdate = readinessEvaluation.IsReadyToUpdate,
    IsOSReady = readinessEvaluation.IsOSReady,
    // ... altre proprietà
};
```

## Criteri di Readiness (SecureBootReadinessService)

### 1. **Versione OS** (`IsOSReady`)

**Requisiti minimi:**

| OS Version | Build Minimo | Note |
|------------|-------------|------|
| Windows 10 22H2 | 10.0.19045 | Ultimo Windows 10 supportato |
| Windows 10 21H2 | 10.0.19044 | In supporto fino a giugno 2025 |
| Windows 11 21H2 | 10.0.22000 | Prima versione Windows 11 |
| Windows 11 22H2 | 10.0.22621 | Versione corrente |
| Windows 11 24H2 | 10.0.26100 | Ultima versione disponibile |

**Logica di valutazione:**
```csharp
var currentVersion = new Version(osVersion);
var requiredVersion = new Version(minimumVersion);
IsOSReady = currentVersion >= requiredVersion;
```

### 2. **Windows UEFI CA 2023** (`HasWindowsUEFICA2023`)

**Verifica:**
- Cerca il certificato nel database `SignatureDatabase` (db)
- Controlla il thumbprint: `ConfiguredThumbprint`
- Oppure controlla il subject: contiene "Windows UEFI CA 2023"

```csharp
HasWindowsUEFICA2023 = dbCertificates.Any(cert =>
    cert.Thumbprint?.Equals(_options.WindowsUEFICA2023Thumbprint, StringComparison.OrdinalIgnoreCase) == true ||
    cert.Subject?.Contains("Windows UEFI CA 2023", StringComparison.OrdinalIgnoreCase) == true);
```

### 3. **Certificati OEM** (`AreOemCertificatesValid`)

**Filtro certificati OEM:**
```csharp
var oemCertificates = dbCertificates
    .Where(cert => cert.IsMicrosoftCertificate == false && !string.IsNullOrEmpty(cert.Subject))
    .ToList();
```

**Soglie di scadenza:**
- **Critici**: < 90 giorni (`CertificateExpirationCriticalDays`)
- **Attenzione**: < 180 giorni (`CertificateExpirationWarningDays`)

**Valutazione:**
```csharp
AreOemCertificatesValid = expiredCount == 0 && criticalCount == 0;
```

### 4. **Readiness Generale** (`IsReadyToUpdate`)

**Formula:**
```csharp
IsReadyToUpdate = IsOSReady && AreOemCertificatesValid && HasWindowsUEFICA2023;
```

**Tutti e 3 i criteri devono essere soddisfatti.**

## Integrazione con Altre Funzionalità

### Device List
La card di readiness mostra informazioni dettagliate che integrano la colonna "Ready to Update" nella Device List (`/Devices/List`).

**Relazione:**
- Device List: overview rapida con badge colorato
- Readiness Card: breakdown dettagliato dei criteri

### Secure Boot Update Progression
La card di readiness appare **prima** della Secure Boot Update Progression, fornendo il contesto per capire se il dispositivo è pronto prima di visualizzare lo stato del deployment.

### Certificates Card
I dettagli dei certificati OEM nella readiness card sono un riassunto. La Certificates Card più in basso mostra i certificati completi con tutte le proprietà X.509.

## Best Practices

### Per IT Administrators

1. **Workflow Consigliato:**
   - Controlla la readiness card prima di inviare comandi di deployment
   - Risolvi i problemi indicati in "Azioni Consigliate"
   - Verifica nuovamente dopo le correzioni

2. **Prioritizzazione:**
   - **Alta priorità**: Certificati scaduti o critici
   - **Media priorità**: OS obsoleto
   - **Bassa priorità**: Certificato CA 2023 mancante (se device è nuovo)

3. **Monitoraggio:**
   - Usa Device List per identificare dispositivi non pronti
   - Drill-down su Details page per dettagli specifici
   - Traccia le correzioni via Report History
